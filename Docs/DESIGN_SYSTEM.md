# 设计规范

封面承担色彩，音乐内容承担层级。保持「听听 · 音乐库 · 搜索」和统一迷你播放条，低频操作在对应内容旁展开。

## 基础

`App/Design/Theme.swift` 是基础控件与动效的实现入口。

| 元素 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | `#F5F5F2` | `#111213` |
| 正文 | `#20211F` | `#F4F4EF` |
| 次要文字 | `#62655E` | `#A8ABA4` |
| 强调色 | `#4C5943` | `#CAD1BE` |
| 内容表面 | `#E9EBE5` | `#20221F` |

使用系统语义字号，正文采用 body，说明采用 subheadline / caption。正文基础 17 pt，随 Dynamic Type 缩放；不以固定高度裁切可变长度文字。页面边距 20 pt，间距沿用 4 / 8 pt 节奏，常规面板圆角 14 pt，操作区域至少 44 × 44 pt。

基础实色对比度计算：浅色正文约 14.80:1、辅助文字 5.43:1；深色正文约 17.00:1、辅助文字 8.06:1。透明材质、占位文字及叠图仍须逐处验收。

完整方形封面使用适配尺寸的缓存图。取色只作为首页主区、详情和播放器的低透明度氛围；提高对比度或减少透明度时关闭该氛围。主要信息始终使用固定语义文字色。

## 操作与动效

| 动作 | 时长 | 行为 |
| --- | --- | --- |
| 按钮按下 | 120 ms | 小幅缩放和透明度反馈，禁用状态降低透明度 |
| 喜欢、局部状态 | 180 ms | 只过渡对应状态 |
| 歌词跟随 | 220 ms | 手动滚动立即停止跟随 |
| 播放器展开 | 280 ms | 封面与播放器关联；支持收起 |
| 封面氛围变化 | 500 ms | 仅曲目变化时过渡 |
| 减少动态效果 | 100 ms | 以短淡入淡出代替位移、缩放 |

明确修改内容的操作可提供轻触感。普通导航不重复震动。按钮、迷你播放条、播放器和锁屏信息读取同一播放状态，未实际播放时不会提前报告成功。

## 页面规则

- 首页区分未登录、收藏为空、队列为空及会话失效；已有资料始终保留。
- 歌曲使用平整列表，专辑使用网格。分类分别保留筛选、排序和浏览位置。
- 播放器将封面及元数据放入可滚动区域，进度、播放、歌词和队列入口保持可达。大字体优先缩小封面。
- AI 成功后以结果为主，需求可重新展开。试听使用明确标签和固定结束入口。
- 错误在对应内容区域提供重试；新请求超过 300 ms 才出现局部等待状态。已有结果不因刷新或取消消失。
- 个人签名小组件显示“打开应用继续听”，不展示无法共享的实时状态。
- 诊断分页预览，完整文件由后台编码；不能让诊断页面本身因长文本阻塞界面。

新增界面沿用这些规则；实际覆盖与尚未验收的环境以 [质量记录](QUALITY.md) 为准。

## 找回与复用

音乐库顶部以两个轻量文字入口连接“最近听过”和“我的编排”，窄屏及辅助字号下纵向排列，沿用 44 pt 触控区域。历史使用日期分组的平整歌曲列表；本机编排使用 72 pt 封面组合、标题和时长，不与专辑网格混用。搜索和页面返回保留浏览位置。

新建编排直接展示输入，已有编排直接展示音乐结果。本机保留与网易云保存使用不同文案。删除与保留只过渡相关条目；减少动态效果时采用短淡入淡出。首页主按钮读取统一播放状态，在播放或准备期间提供暂停。

### 起点与替换

“沿着这首听”使用 64 pt 完整封面与短说明，入口与歌曲上下文相连。局部替换保留原曲目列表，44 pt 勾选区与歌曲试听分开；底部固定展示所选数量和生成／取消按钮，长列表中仍可操作。勾选使用 180 ms 状态过渡，减少动态效果时缩短为 100 ms。

替换预览逐项对照原曲与新曲，底部固定“采用这次调整”，正文显示完整歌曲带来的实际时长变化。本次反馈默认折叠，原因可查看与删除；不添加常驻 AI 浮层。生成中的局部等待提示延迟 300 ms 出现，输入键盘在开始请求时收起。
